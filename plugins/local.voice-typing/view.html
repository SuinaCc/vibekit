手机当输入法 / 遥控器
语音页用豆包输入法按住说话，说完点回车发送，也可用退格/换行/清空修改；开启自动粘贴时会等输入停止 1 秒再发送。按键页可直接控制电脑键盘和宏。

无需 API Key，无需安装证书。手机与电脑在同一局域网，扫码即可使用。

手机连接

1. 手机扫码打开网页（普通 HTTP，不用装证书）。
2. 语音页：点输入框，用豆包输入法语音键按住说话，说完点「回车发送」。
3. 按键页：点常用按键或自定义宏控制电脑。
4. 扫码后切换到目标窗口；本插件窗口可以关闭，会话会继续运行。

按键与宏

手机「按键遥控」页会显示这些按钮，点「编辑」可修改已有宏。支持组合键和多步序列，例如：ctrl+s、alt+tab、win+d；多步：ctrl+a, ctrl+c, sleep:150, alt+tab, ctrl+v。锁屏宏会调用系统锁屏接口，不依赖模拟按键。

手机页面每 5 秒自动刷新宏列表

连接设置

默认 47640；如果端口被占用可以改成其它 1024–65535 的端口。
